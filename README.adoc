= Cite Libre - Ops

image:https://img.shields.io/github/license/citelibreorg/ops.svg[License]

**CiteLibre** is the software suite provided by Lutece to help you implement a wide range of digital services ready for deployment with your brand image.
The services (RendezVous, Service'EZ, Particip'EZ) are developed on the Lutece platform, pre-assembled and containerized for easy deployment, and 100% open source.

This repository holds the **Kubernetes** deployment of CiteLibre, described with https://www.yupiik.io/bundlebee/[Yupiik Bundlebee], and helper scripts to try it on a local Minikube.

== 🗂️ Repositories

CiteLibre is split into three repositories:

[cols="1,3"]
|===
| Repository | Content

| https://github.com/citelibreorg/packaging[packaging]
| Maven assembly of each service (Lutece core + plugins + configuration) and Docker image build (Jib)

| https://github.com/citelibreorg/demo[demo]
| Docker Compose stack to run the services locally: shared platform (Keycloak, Matomo, Solr, Elasticsearch/Kibana, ...), one compose file per service, Cypress e2e tests

| https://github.com/citelibreorg/ops[ops] (this one)
| Kubernetes deployment descriptors (Yupiik Bundlebee) and Minikube helper scripts
|===

== 📁 Layout

[cols="1,3"]
|===
| Path | Content

| `pom.xml`
| Bundlebee Maven plugin configuration

| `bundlebee/manifest.json`, `bundlebee/manifests/`
| Bundlebee manifests: the `citelibre` alveolus deploys the namespace, the shared platform (`platform.json`) and the applications (`applications.json`)

| `bundlebee/kubernetes/`
| Kubernetes descriptors: namespace, templates (application, database, database init job), platform components, applications, ingress

| `bundlebee/resources/`
| Files injected in the descriptors: database init script and SQL files (one folder per database), Keycloak theme

| `bundlebee/environments/default.properties`
| Default placeholder values (local development values)

| `bundlebee/placeholders.descriptions.properties`
| Description of each placeholder

| `scripts/`
| Minikube helper scripts
|===

== 🧱 What is deployed

* **Platform**: MariaDB (shared by all databases), Elasticsearch, Solr and Keycloak (realms `citelibre_backoffice` / `citelibre_frontoffice`, CiteLibre login theme).
* **Applications**: CiteLibre RendezVous.
* **Ingress**: a single entry point serving `/keycloak` and `/citelibre-rendezvous`, like the httpd of the demo.

Each database (`keycloak`, `rendezvous`) is created by a Job that imports the SQL files of `bundlebee/resources/sql/<name>/`. The Job is idempotent (it does nothing when the database already exists), so redeploying is safe. To reset a database, drop it and redeploy.

The SQL files and the Keycloak theme are copies of the https://github.com/citelibreorg/demo[demo] ones: keep them in sync when the demo data set changes.

== 🔧 Getting Started

Pre-requisite: Apache Maven >= 3.6.3, Java >= 17 and a Kubernetes cluster reachable through your current kube context, with an nginx ingress controller.

Deploy the `citelibre` alveolus:

[source,bash]
----
mvn -e bundlebee:apply@k8s [-Dbundlebee.debug=true] [-Ddeployment.alveolus=citelibre]
----

Delete it:

[source,bash]
----
mvn -e bundlebee:delete@k8s [-Dbundlebee.debug=true] [-Ddeployment.alveolus=citelibre]
----

`-Dbundlebee.debug=true` enables dry-run and verbose mode. Any placeholder can be overridden with `-D<placeholder>=<value>`, for instance `-Dcitelibre.public.url=https://citelibre.example.org`.

=== Local deployment with Minikube

The `scripts/` directory wraps Minikube around the commands above:

[source,bash]
----
./scripts/0_install.sh   # install minikube
./scripts/1_start.sh     # start minikube with the metrics-server and ingress addons
./scripts/2_status.sh    # minikube status
./scripts/3_deploy.sh    # load the local CiteLibre images into minikube and deploy the citelibre alveolus
./scripts/4_expose.sh    # expose the ingress on http://localhost:8088 (keep it running)
./scripts/5_destroy.sh   # delete the citelibre alveolus
./scripts/6_listPods.sh  # list pods and the URLs of the deployed services
./scripts/7_stop.sh      # stop minikube
./scripts/8_delete.sh    # delete the minikube cluster
----

The CiteLibre images are built from the https://github.com/citelibreorg/packaging[packaging] repository (`mvn clean package -Passembly,rendezvous,docker`), then loaded into minikube by `3_deploy.sh`.

The first deployment takes a few minutes (database imports, Keycloak first start). Then, with `4_expose.sh` running:

- Back office at http://localhost:8088/citelibre-rendezvous/jsp/admin/AdminMenu.jsp : admin@citelibre.org/coucou
- Front office at http://localhost:8088/citelibre-rendezvous/jsp/site/Portal.jsp : test@citelibre.org/coucou
- Keycloak administration at http://localhost:8088/keycloak/admin/

The applications must be reached on `http://localhost:<port>`: the Keycloak clients only allow `http://localhost*` redirect URIs. The port is the `citelibre.public.url` placeholder (`http://localhost:8088` by default).
